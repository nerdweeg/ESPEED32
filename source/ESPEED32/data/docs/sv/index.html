ESPEED32 Bruksanvisning

Användarguide för bilbana: uppstart, de viktigaste körreglagen, menyer samt säkerhetskopiering och återställning.

Öppna kontrollens webbgränssnitt
  • Källkod för firmware: ESPEED32 (source/ESPEED32/).
  • Lokala manualer i repot: Quick Start + Extended Guide (DOC-mappen, DOCX/PDF).
  • ACD-referens: ACD PRO Manual 11E.
  • CarSteen-referens: CS 4.2 Owner's Guide.

Användardokumentationen på espeed32.com visar alltid den senast publicerade versionen. Kopian som ligger i kontrollen följer den firmware som faktiskt är installerad och uppdateras tillsammans med den.

1. Snabbstart

  1. Starta kontrollen som vanligt.
  2. Vrid encodern för att bläddra mellan menyvalen.
  3. Kort tryck på encodern: börja/avsluta redigering av ett värde eller öppna en undermeny.
  4. Kort tryck på bromsknappen under redigering: avbryt (det ursprungliga värdet återställs).
  5. Långt tryck på encodern (~1 s): växla mellan LIST och race-vyn GRID (när race-vyn inte är OFF).

2. Uppstart, kalibrering och självtest

  • Kalibrera om avtryckaren efter en firmwareuppdatering, eller om avtryckarens mekanik har ändrats.
  • Ström PÅ: normal uppstart, därefter RUNNING.
  • I TLE493D-byggen känns sensorvariant och adress av automatiskt vid uppstart (ingen manuell adressändring behövs).
  • Sensorfamiljen för avtryckaren väljs när firmware kompileras. Standardreleaser och -byggen använder TLE493D. Kontroller byggda med AS5600, AS5600L, MT6701 eller ANALOG måste använda en firmware byggd för rätt sensorfamilj.
  • Håll encoderknappen intryckt vid uppstart: kalibrering av avtryckaren.
  • Håll bromsknappen intryckt vid uppstart: självtest (9 steg).
  • Håll bromsknappen intryckt i 5 s vid uppstart: nöd-WiFi (AP). Hotspoten startar i AP-läge även om WiFi är inställt på HOME, så att kontrollen kan konfigureras från en mobil när encodern inte går att vrida.

Kalibrering steg för steg

  1. Håll encodern intryckt vid uppstart tills kalibreringsskärmen visas.
  2. Tryck in och släpp avtryckaren helt flera gånger.
  3. Tryck en gång på encodern för att spara kalibreringen.
  4. Kontrollera att gasen visar 0 % med släppt avtryckare och 100 % med helt intryckt avtryckare.

Avtryckarens mekanik

  • Slaglängden kan ändras mekaniskt med stoppskruven baktill.
  • Hur avtryckaren fjädrar tillbaka beror på fjäderns förspänning. Justera fjäderfästet eller spännreglaget försiktigt.
  • Kalibrera om avtryckaren innan du kör efter att du har ändrat slaglängd eller fjäderspänning, eller efter att kontrollen har varit öppnad.

3. Skärm, race-vy och INFO

Det här avsnittet samlar det du ser på OLED-skärmen: språk, textstil, race-layout, statusrad och systeminformation.

Språk och skärm

  • SKARM -> SPRAK väljer språk i menyerna: NOR/ENG/ESP/DEU/ITA/NLD/POR/SVE.
  • SKARM -> TERMER väljer namnen på parametrarna. Det fungerar med alla språk:
  • ESPEED (standard): de vanliga namnen BRAKE/SENSI/ANTIS/CURVE/FADE/LIMIT, översatta till valt språk.
  • CS: CarSteen-termer (ATTCK/CHOK2/PROFL/CHOK1).
  • ACD: ACD-termer där det finns en direkt motsvarighet (SENSI och CHOKE för gräns). ANTIS behålls som antispinn eftersom ACD-manualen inte har någon egen Choke2-term.
  • CHOK1 (CS) och CHOKE (ACD) går åt motsatt håll mot LIMIT: CHOKE = 100 - LIMIT. CHOKE 0 betyder ingen strypning (full fart), och ett högre värde stryper mer. Inställningen sparas som LIMIT, så byte av terminologi ger samma toppfart.
  • Uppgradering från v6.14 eller äldre: en kontroller som stod på språket CS eller ACD startar på engelska med motsvarande terminologi. Säkerhetskopior från före v6.15 återställer allt utom språket.
  • SKARM -> STIL väljer om etiketterna visas som UPPER eller Pascal.
  • SKARM -> TEXTSTRL växlar textstorleken i listor och menyer mellan STOR och liten.
  • SKARM -> AVANCER. styr om FADE, PWM_F och BROMS+ visas i huvudmenyn. Med AV döljs raderna för en enklare meny, men de sparade bilvärdena gäller fortfarande.
  • SKARM -> STEG öppnar undermenyn för stegstorlekar med ANTISPIN, BROMSSTEG och SENSISTEG.
  • SKARM -> STEG -> ANTISPIN öppnar inställningarna för hur antispinn visas: välj enhet (MS / % / TEXT) och encoderns stegstorlek för varje enhet.
  • SKARM -> STEG -> BROMSSTEG anger hur många procent encodern ändrar BROMS per klick (0,1–50,0 %, standard 1,0 %). Ställs in under INSTALLN → SKARM → STEG → BROMSSTEG.
  • SKARM -> STEG -> SENSISTEG anger encoderns stegstorlek för SENSI i steg om 0,1 % (0,1–5,0 %, standard 1,0 %). Ställs in under INSTALLN → SKARM → STEG → SENSISTEG.
  • Motorns PWM-utgång använder 10 bitars upplösning, så steg på 0,1 % för BROMS/SENSI behålls hela vägen genom beräkningarna och PWM-hårdvaran.

Race-vy (LIST eller GRID)

  • LIST klassisk meny med alla huvudval.
  • GRID race-skärm för snabba ändringar under körning.
  • SKARM -> RACELAGE: AV / FULL / ENKEL.
  • FULL: BROMS, SENSI, ANTIS, KURVA (+ BIL om RACESWP är PA).
  • ENKEL: BROMS, SENSI (+ BIL om RACESWP är PA).
  • Långt tryck på encodern växlar mellan LIST och GRID.

Statusrad och INFO

  • STATUSRAD: 4 fasta fält. Varje fält kan visa OUT%, GAS, BIL, AMP, VOLT, VBAT, ID, BROMS eller vara tomt. AMP visar mA under 1000 och A däröver.
  • BROMS i statusraden visar aktivt bromsläge och värde i realtid: Bxxx% = vanlig BROMS, Axxx% = Alt.broms, Qxxx% = Rel.broms QUICK, Dxxx% = Rel.broms DRAG, NONE = ingen broms aktiv just nu. Koden kan ändras snabbt under körning.
  • VBAT visar spänningen på det valfria interna batteriet. I standardprofilen för kortet mäts den på GPIO15 / ADC2, så värdet kan sluta uppdateras medan WiFi är aktivt.
  • ID visar kontrollens enhets-ID, till exempel #A3B4. Det är de 4 sista hex-tecknen i MAC-adressen, samma som i WiFi-namnet (ESPEED32_A3B4), så att du kan skilja kontroller åt på banan och i WiFi-listan.
  • Medan WiFi är aktivt visar statusraden WIFI. Det använder det första tomma fältet om det finns, annars tar det tillfälligt över fält 4.
  • INFO visar firmware- och dataversion, identifierad avtryckarsensor, chipdetaljer, flash/heap, MAC-adresser samt byggdatum och -tid.

4. BIL-menyn och bilparametrar

Menyn *BIL* hanterar bilprofilerna. Varje profil har egna Car Params: BROMS, SENSI, ANTIS, KURVA, FADE, PWM_F, BROMS+ och GRANS. Det är samma parametergrupp som du senare möter i Advanced Config Editor. Om SKARM -> AVANCER. är AV döljs FADE, PWM_F och BROMS+ i huvudmenyn, men de sparade profilvärdena gäller fortfarande.

  • VALJ: välj aktiv bilprofil (0-19).
  • NAMNGE: namneditor med 5 tecken (ASCII 32-122). Se ASCII-tabell.
  • RACESWP: PA gör att du kan byta profil direkt i GRID-vyn. Standard: AV.
  • KOPIA: kopiera från en profil till en annan, eller till ALLA profiler.
  • ATERSTALL: återställ alla bilprofiler (med bekräftelse).

5. Körparametrar

Det här avsnittet samlar de viktigaste inställningarna som avgör hur kontrollen känns på banan. De längre förklaringarna ligger i hopfällbara paneler så att avsnittet blir lättare att överblicka.

BROMS och BROMS+

BROMS

När avtryckaren är helt släppt bromsar kontrollen med värdet BROMS.

BROMS+ i huvudmenyn öppnar undermenyn för avancerad broms. Där finns Alt.broms och Rel.broms.

Alternativ broms (Alt.broms)

  • Alt.broms är en alternativ bromsprocent (0-100 %), inte en relativ minskning.
  • Den används bara när avtryckaren står på 0 och du håller in bromsknappen.
  • Om statusraden visar OUTPUT visas Bxxx% medan bromsknappen hålls in.
  • Typisk användning: tillfälligt hårdare eller mjukare inbromsning inför kurvor utan att ändra grundinställningen.
  • Vissa förare vill ha Alt.broms lägre än vanlig BROMS för en mjukare knappbroms, andra vill ha den högre för en hårdare broms. Det är mest en fråga om smak och hur bilen känns.

Släppbroms (Rel.broms)

  • Rel.broms är släppbromsen och har tre lägen: AV, QUICK och DRAG.
  • QUICK är den gamla förbromszonen: under vald Zon bryter kontrollen drivningen och bromsar med Level.
  • DRAG verkar bara medan du aktivt släpper avtryckaren. Gasen är kvar, men det läggs till motståndsbroms under släppet. Det känns mjukare än QUICK.
  • Zon används bara av QUICK. Där är det en verklig nollzon nära släppt avtryckare.
  • Med QUICK aktivt är det alltså normalt att skärmen visar några %T medan utgången fortfarande är 0%, tills avtryckaren kommer över vald zon.
  • Den viktigaste skillnaden: QUICK bryter helt inne i zonen, medan DRAG behåller gasen och bara lägger till broms medan avtryckaren rör sig mot släppt läge.
  • Typisk användning av QUICK: banor eller bilar som behöver en tydlig tidig broms. Exempel: Zon 6-10 % och Level 70-100 % för en stark och upprepbar broms när du börjar släppa den sista delen av slaglängden.
  • Typisk användning av DRAG: nervösa bilar som blir för ryckiga med QUICK. Exempel: Level 20-50 % för mjuk inbromsning under släppet, utan känslan av att allt bryts till noll.
  • Område för QUICK Zon: 0-50 %. Område för Level: 0-100 %.
  • Använd QUICK för en tydlig tidig broms. Använd DRAG för mjukare hjälp vid släpp utan den abrupta känslan av full quick-broms.

ANTIS i praktiken

  • ANTIS är ingen full fördröjning av avtryckaren. Bilen ska fortfarande reagera när du börjar trycka in avtryckaren.
  • Vid låg effekt kopplas antispinn förbi, så den allra första delen kan fortfarande kännas direkt.
  • När effekten är tillräckligt hög begränsar ANTIS hur snabbt effekten får öka.
  • Högre ANTIS = längre/långsammare ramp från startpunkten för antispinn upp mot begärd effekt.
  • Den verkar bara när effekten ökar. Att släppa avtryckaren, rulla och bromsa sker fortfarande direkt.

FADE i praktiken
  • FADE skapar en mjuk ramp 0 -> SENSI i den första delen av slaglängden.
  • FADE = 0% stänger av den och behåller den gamla direkta känslan.
  • Prova 5-15% om bilen känns för ryckig precis när SENSI börjar verka.
  • Tänk på FADE som en extra första punkt i grafen: den ändrar bara den allra lägsta delen, medan KURVA fortfarande formar resten.
Om linjäritet
  • GRANS: linjärt tak för begärd effekt i %. Den verkliga toppfarten på banan är inte helt linjär.
  • BROMS: linjärt broms-/motståndskommando i %. Den verkliga bromskänslan beror på motor, däck och banans grepp.
  • SENSI: linjärt golv för lägsta effekt i %, men ingen linjär förstärkning över hela slaglängden eftersom KURVA formar resten.
  • FADE: linjär i % av slaglängden. Den påverkar bara den första delen av avtryckaren och lämnar sedan över till KURVA.
  • ANTIS: främst en tidsinställning i ms, ingen ren fördröjning. När antispinn är aktivt ger ett högre värde en längre/svagare ramp, men den totala känslan är inte helt linjär eftersom gränsen för förbikoppling vid låg fart också flyttas med inställningen.

GRANS i praktiken
  • GRANS 100 låter kontrollen nå full duty när avtryckaren och kurvan kräver det.
  • GRANS 70 begränsar högsta duty till cirka 70 %, även med helt intryckt avtryckare.
PWM_F i praktiken
  • PWM_F ändrar hur ofta utgången slår om, inte själva begärda duty.
  • Med GRANS 100 kan delgas fortfarande ge delvis duty. Med GRANS 70 stannar full avtryckare vid cirka 70 % duty.
  • Vid samma duty använder 1 kHz färre och bredare pulser, medan 5 kHz använder fler och smalare pulser under samma tid.

6. INSTALLN, STROM och strömförbrukning

INSTALLN samlar de globala systeminställningarna som inte hör till en enskild bilprofil.

Undermenyn STROM

  • SKSPR: skärmsläckarens text för rad 1/rad 2, tidsgräns och visa nu.
  • VILA: automatisk viloläge efter en tid + manuell vila nu (väck med encoderknappen).
  • DJUP VILA: automatisk djup vila (0 eller 2-30 min) + manuell.
  • UPPSTART: välkomstfördröjning 0-990 ms i steg om 10 ms.
  • VIN KAL.: mät den verkliga banspänningen med en multimeter, ställ in samma värde på kontrollen och klicka för att kalibrera ADC-spänningsskalan. Används bara om VIN-värdet är märkbart fel.

Val i INSTALLN

  • HARDWARE: encoderns riktning, externa potentiometrar, information och åsidosättning för avtryckarsensorn samt självtest.
  • STATS: visa eller dölj STATS i huvudmenyn. Standard AV.
  • WIFI: WiFi i bakgrunden, direkt infosida, QR-kod och automatisk avstängning av WiFi.
  • LOGGING: start/stopp av lokal telemetriloggning samt en egen tidsgräns för automatisk avstängning (standard 30 min).
  • LAS: ställ in låset för inställningar. Slå på menyvalet LAS i huvudmenyn (standard AV), ange hålltiden för genvägen med bromsknappen (AV eller 1–10 s, standard 5 s) och välj om bekräftelserutan LOCKED/UNLOCKED ska visas.

Undermenyn HARDWARE

  • ENC.INVERT: vänd encoderns riktning globalt om menyn känns baklänges på din hårdvara.
  • EXT.POT.: koppla POT 1 och POT 2 till AV, BROMS eller SENSI som direkt åsidosättning.
  • TRIGGER: visar avtryckarsensorns familj och aktiva typ. I TLE493D-byggen kan du också åsidosätta TYP mellan AUTO, W2B6, W2B6_A0 och P3B6.
  • PWM_F MAX: globalt tak för PWM_F. Välj 5, 10, 20 eller 25 kHz. PWM_F kan sedan ställas in i steg om 0,1 kHz upp till taket. Sänker du taket begränsas alla bilprofiler till det. Nackdelen med hög PWM (över cirka 20 kHz): motordrivaren slår om oftare per sekund, så omslagsförlusterna ökar och drivaren blir varmare. Omslagsflankerna tar också en större del av varje period, så responsen allra längst ner och allra högst upp på gasen blir mindre linjär. Använd den lägsta frekvensen som känns bra, och kontrollera drivarens temperatur om du går över 20 kHz.
  • TEST: kör självtestet i 9 steg för OLED, knappar, avtryckare och utgångar.

Internt batteri (valfritt)

Vissa hårdvaruvarianter kan ha ett litet litiumbatteri med en cell för inställningar när kontrollen inte är ansluten till banan. Det laddas när kontrollen får ström från banan eller via USB. Batteriet är tänkt för menyändringar, förberedelser före race, justeringar vid filbyte eller för att slippa vänta på uppstart innan banan får ström. Det är inte tänkt för lång drift på egen hand.

Drifttiden nedan avser användning av kontrollen när den inte är ansluten till banan. Laddströmmen varierar med laddare och kort, men om laddningen ligger nära 200 mA och kontrollen drar runt 100 mA blir drifttiden utanför banan ofta ungefär dubbelt så lång som laddtiden. Verklig laddtid för litium är ändå lite längre än den enkla räkningen, eftersom den sista delen av laddningen går långsammare nära fullt.

7. Körtips

  • Ändra en parameter i taget och kör 5-10 varv före nästa ändring.
  • Justera i den här ordningen: SENSI, sedan FADE, sedan BROMS, ANTIS, KURVA och sist PWM_F.
  • 1/32-bilar på banor med lågt grepp: prova högre ANTIS (runt 100-150 ms) och mjukare KURVA (<50).
  • 1/24-bilar på banor med högt grepp: ofta lägre ANTIS (0-40 ms) och mer direkt KURVA (50-70).
  • Använd BROMS+ -> Alt.broms som ett tillfälligt kurvverktyg i stället för att ändra BROMS mellan heaten.
  • Använd BROMS+ -> Rel.broms QUICK med låg zon (5-12 %) och medelhög nivå (40-70 %) för tydligare tidig broms. Prova DRAG runt 20-50 % om du vill ha hjälp vid släpp utan nollzon.
  • Om bilen tar i för hårt precis när avtryckaren börjar verka: behåll SENSI där du vill ha den och lägg först till lite FADE.
  • Om bilen spinner tidigt i slaglängden: sänk SENSI eller öka ANTIS.
  • Om bilen känns slö ut ur kurvor: höj SENSI något eller minska ANTIS.

8. Loggning, WiFi/USB-säkerhetskopia, återställning och OTA

Loggning

  1. Öppna INSTALLN -> LOGGING.
  2. START NU/STOPP NU: startar eller stoppar lokal telemetriloggning direkt.
  3. AUTO AV: ställ in tidsgränsen för loggning (1-120 min, standard 30 min).
  4. Själva loggningen kräver inte WiFi. Du kan ha WiFi avstängt och använda USB/WebSerial senare, eller slå på WiFi separat för att följa loggningen live i webbläsaren.
  5. Om WiFi redan är aktivt när loggningen startar, förblir WiFi på så länge loggningen pågår.

WiFi

  1. Öppna INSTALLN -> WIFI för att komma till WiFi-undermenyn.
  2. START WIFI/STOPP WIFI: startar eller stoppar WiFi i bakgrunden direkt.
  3. LAGE: växlar mellan AP och CLIENT.
  4. INFO SIDA: öppnar WiFi-sidan direkt och startar WiFi automatiskt. När du lämnar infosidan stoppas WiFi igen (om inte bakgrundsläget startades först).
  5. I AP-läge sänder kontrollen ESPEED32_XXXX med lösenordet espeed32. VISA QR finns bara i AP-läge.
  6. I CLIENT-läge måste du först ange WiFi-namn (SSID) och lösenord under Advanced Config Editor -> Network. Klientläget får adress via DHCP från din router/ditt nätverk och visar ingen QR-kod.
  7. Om anslutningen i klientläge misslyckas går kontrollen automatiskt tillbaka till AP, så att du kan komma in igen och rätta inställningarna.
  8. AUTO AV: ställ in tidsgränsen för WiFi i bakgrunden (1-120 min, standard 10 min).
  9. Öppna IP-adressen som visas på OLED-skärmen i webbläsaren. I AP-läge är det oftast 192.168.4.1. I CLIENT-läge är det adressen som din router har delat ut via DHCP.
  10. Första sidan är kontrollens öppna startsida. Känsliga verktyg som Controller Panel, Backup, Restore, telemetri, OTA och Advanced Config Editor skyddas av kontrollens inloggning.
  11. Standardinloggning är användarnamnet espeed32 och lösenordet espeed32. Den aktuella inloggningen visas också på kontrollens WiFi-infosida.
  12. Säkerhetskopior innehåller inte lösenordet för klient-WiFi eller kontrollens inloggning. Vid återställning behålls de WiFi- och inloggningsuppgifter som redan finns sparade i kontrollen.

WiFi ökar strömförbrukningen för kontrollens elektronik från cirka 100 mA till 150 mA, ungefär 50 % mer. På enheter med internt batteri bör du använda WiFi sparsamt och stänga av det när du är klar.

Statusraden medan WiFi är aktivt: WIFI använder det första tomma fältet. Finns inget tomt fält visas fält 4 som WIFI tills WiFi stängs av.

Advanced Config Editor

  • Webbportalen har också en Advanced Config Editor för ändringar live.
  • Global Config ändrar inställningar för hela kontrollen. Car Params ändrar vald bilprofil.
  • Under Global Config kan du också ställa in SSID/lösenord för klient-WiFi och kontrollens inloggningslösenord.
  • I Car Params kan du läsa in och ändra valfri bilprofil direkt från listan, även om en annan profil är aktiv i kontrollen.
  • Refresh from device läser in de aktuella värdena från kontrollen igen.
  • Apply (RAM only) låter dig testa ändringar live utan att först skriva till flash. Det passar bra för att prova broms, gas, antispinn, kurva, fade och släppbroms på banan.
  • Apply + Save to flash sparar samma värden permanent när du är nöjd med testet.
  • På kontrollens WiFi-sida fungerar editorn direkt i webbläsaren via WiFi. På espeed32.com kräver samma editor en USB-anslutning via WebSerial.

USB

  1. Öppna INSTALLN -> USB INFO.
  2. Använd Chrome/Edge (WebSerial).
  3. Säkerhetskopiering och återställning fungerar via USB. OTA kräver WiFi.
  4. Automatisk parad OTA installerar det officiella standardparet, som använder standardbygget för TLE493D.
  5. Om din kontroll använder en annan sensorfamilj för avtryckaren, ladda upp rätt sensorspecifik firmwarefil manuellt tillsammans med SPIFFS-filen från samma release.
  6. På Windows innebär flash_all.sh oftast Git Bash eller WSL. Arduino IDE kan fortfarande ladda upp sketchen, men sensorfamiljen för avtryckaren väljs fortfarande vid kompilering.

Bryt aldrig strömmen under en OTA-uppladdning.
